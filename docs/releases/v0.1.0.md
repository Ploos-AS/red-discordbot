# Red-DiscordBot container v0.1.0

Initial Ploos AS stable container release for Red-DiscordBot.

## Included

- Red-DiscordBot 3.5.24 pinned at image build time
- Python 3.11 slim-bookworm runtime
- non-root UID/GID 1000
- persistent /data
- automatic JSON instance bootstrap
- Discord token via mounted secret (preferred) or environment variable
- tini as PID 1
- local process healthcheck
- ffmpeg, git and OpenSSH client for Red runtime features
- Docker Compose and rootless Podman Quadlet examples
- multi-architecture publication for linux/amd64 and linux/arm64
- GHCR stable, minor, latest and edge channels
- BuildKit SBOM and provenance attestations
- container hardening with no-new-privileges and dropped capabilities in deployment examples
- MIT packaging license with GPL-3.0-only upstream attribution

## Image

`ghcr.io/ploos-as/red-discordbot:0.1.0`

Release promotion is allowed only after static validation, image build, bootstrap,
entrypoint, secret-handling, healthcheck and container smoke tests pass.
