# Red-DiscordBot container v0.2.0

Second Ploos AS stable container release candidate for Red-DiscordBot.

## Included

- Red-DiscordBot 3.5.24 pinned at image build time
- independent container/upstream version management
- qualified runtime bootstrap and lifecycle behavior
- qualified persistence, upgrade, and rollback from v0.1.0
- non-root UID/GID 1000
- read-only root filesystem in deployment defaults
- constrained writable `/tmp` tmpfs
- persistent writable `/data`
- dropped Linux capabilities and `no-new-privileges`
- local healthcheck and graceful SIGTERM handling through `tini`
- Docker Compose and rootless Podman Quadlet deployment definitions
- multi-architecture publication for `linux/amd64` and `linux/arm64`
- BuildKit SBOM and maximum-mode provenance attestations
- MIT packaging license with GPL-3.0-only upstream attribution

## Image

`ghcr.io/ploos-as/red-discordbot:0.2.0`

Stable tags `0.2.0`, `0.2`, and `latest` are promoted only from the `v0.2.0` tag after the complete Container workflow passes.
